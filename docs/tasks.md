# Project tasks

This URL used to contain a hand-maintained implementation backlog. It is no
longer a source of truth and intentionally does not repeat feature status,
platform claims, or release plans.

Use the repository's
[GitHub issues](https://github.com/mherod/get-cookie/issues) for current work,
open bugs, and proposals. Before filing a new issue, search for an existing
one and include only redacted diagnostics.

For contributor workflow, see
[CONTRIBUTING.md](https://github.com/mherod/get-cookie/blob/main/CONTRIBUTING.md).
